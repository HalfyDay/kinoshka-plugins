# Каталог JS-плагинов Kinoshka

Официальная витрина пользовательских источников (вариант C).
Приложение показывает этот список на экране
Источники → Свои → Каталог: установка в один тап, обновление по версии.

Контракт плагина (что должны делать `manifest()`/`resolveMovie()`):
https://github.com/HalfyDay/Kinoshka/blob/main/docs/js-plugins/README.md

## Структура

- `index.json` — витрина: метаданные всех плагинов + `sha256` кода каждого.
  Приложение сверяет хеш после скачивания: подменённый код не встанет.
- `plugins/*.js` — код плагинов (либо файлы авторов, если автор хостит сам —
  тогда в `index.json` лежит его URL, а хеш всё равно наш).

## Формат записи в index.json

```json
{
    "id": "example-embed",
    "name": "Example Embed",
    "author": "@kinoshka",
    "description": "Шаблонный плагин: фильм + сериал/аниме",
    "version": "1.1.0",
    "codeUrl": "https://raw.githubusercontent.com/HalfyDay/kinoshka-plugins/main/plugins/example.js",
    "sha256": "…",
    "sections": ["FILMS"],
    "minAppVersion": "1.1.5"
}
```

- `id` — латиница/цифры/дефис, уникален, навсегда (по нему приложение
  узнаёт установленный плагин при обновлениях).
- `sections` — `FILMS` / `ANIME` / `ADULT` (18+), любые сочетания.
- `version` — любая строка; приложение сравнивает с установленной и
  предлагает «Обновить». Версия в `index.json` обязана совпадать
  с `manifest().version` в коде.
- `sha256` — хеш именно того файла, что лежит по `codeUrl`. Считается так:
  `Get-FileHash plugins/xxx.js -Algorithm SHA256` (Windows) /
  `sha256sum plugins/xxx.js` (Linux). Без хеша запись не принимается.

## Как добавить свой плагин

1. Форкните репозиторий, положите код в `plugins/<id>.js`.
2. Добавьте запись в `index.json` (с хешем).
3. Откройте pull request по шаблону (`.github/PULL_REQUEST_TEMPLATE.md`):
   что за хост, откуда там потоки, на каких 2–3 тайтлах проверено.
4. После вливания плагин появится в приложении в течение суток
   (индекс кэшируется; кнопка «Обновить» в каталоге тянет сразу).

## Правила приёма

- Плагин реально работает (проверяем «Проверить» на устройстве).
- Код читаемый, без обфускации — что прятать в песочнице, непонятно.
- Не ворует чужие потоки под своим именем: указывайте хост честно.
- Новенькие без истории помечаются в приложении «непроверенный»,
  пока не поживут пару недель без жалоб.
